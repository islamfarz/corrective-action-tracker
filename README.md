# Corrective Action Tracker

A small, dependency-free action register for quality teams. Open index.html in a modern browser and select **Add sample action** to try it with fictional data.

- Record findings, owners, due dates, root causes and corrective actions.
- Filter open, closed and overdue actions. The app requires effectiveness evidence and completion details before closure.
- Export the full register as UTF-8 CSV for reporting. Records are stored in the current browser and profile. The CSV is a reporting export and the app does not import it.
- The tool runs locally and does not send records to a server. It is designed for individual use. For team approvals or an auditable change history, use a controlled shared system.
